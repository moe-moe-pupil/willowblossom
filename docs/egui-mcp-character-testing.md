# 使用 egui-mcp 测试角色窗口

角色窗口可在启用 `egui_mcp` Cargo feature 后通过 `egui-mcp` 驱动。检查服务默认只监听
`127.0.0.1:5719`，未设置 `EGUI_INSPECTION` 时不会启动。

```powershell
cargo install egui_mcp --version 0.1.0 --locked
$env:EGUI_INSPECTION = "1"
$env:WILLOWBLOSSOM_EGUI_MCP_CHARACTER = "<已有玩家 QQ 号>"
cargo run --features egui_mcp
```

在 Codex 的 MCP 配置中加入：

```toml
[mcp_servers.egui]
command = "egui-mcp"
args = []
```

连接后先调用 `attach`，再按“观察 → 操作 → 验证”的顺序执行以下回归用例。测试真实数据前应复制
`.data/willowblossom` 到临时工作目录，并让测试进程在该目录运行。

## 角色窗口回归用例

1. **基础资料与创建流程**：修改完成状态、创建步骤、角色名、昵称、图片 URL、立绘变形、等级和经验；
   关闭并重新打开窗口，确认全部值保持。
2. **生命与战斗属性**：分别修改 HP、最大 HP、HP 回复、MP、最大 MP、MP 回复、速度、伤害、承伤、
   治疗、受疗、本轮承伤和本轮受疗；确认最大值约束生效，并验证“清空本轮”。
3. **八项属性**：逐项修改 STR、AGI、DEX、VIT、INT、WIS、K、CHA，确认派生 HP、MP、回复、速度
   和伤害/治疗倍率同步，锁定后不能误改。
4. **Buff**：新增、编辑、应用和删除永久/限时 Buff，覆盖属性加成、伤害、治疗和护盾效果；确认同步后
   手动调整的基础属性不会被覆盖。
5. **背包与装备**：修改金币、格子、物品名、品质、数量、装备位、物品等级、绑定状态；新增/删除物品，
   装备与卸下各装备位，并确认堆叠、背包索引和快捷栏索引保持有效。
6. **物品效果与物品技能**：为背包物品添加、编辑、删除属性效果和技能，覆盖名称、说明、MP、冷却、
   技能类型、目标类型、数量、范围及兑换点。
7. **角色技能**：新增技能并编辑名称、说明、MP、冷却、类型、目标、数量、范围、兑换点、玩家批准和
   GM 批准；验证非法规则提示、技能池复制、删除确认、冷却记录和快捷栏索引迁移。
8. **持久化复验**：完成每组操作后关闭测试进程，重新启动同一临时数据目录，再通过 `query_tree`
   检查显示值并检查临时 `messages.toml`，确认没有字段丢失或串到其他角色。
