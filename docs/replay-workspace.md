# 回放合成工作区

点击主界面右上角的“回放”进入合成工作区。顶部切换“项目 / 编辑 / 镜头 / 导演 / 输出”，左侧显示对应工具，中央保留完整合成画面，底部显示多轨时间轴。拖动左侧和底部面板的分隔线可调整布局；交互后布局会保存。点击“返回主界面”退出工作区。

## 编辑流程

1. 在“项目”中选择发布范围，从现有聊天生成回放，或展开“回放项目数据”载入 JSON。
2. 在时间轴上点击台词、镜头、移动或场景事件定位。拖动标尺拖动播放头；逐帧按钮按输出帧率定位。
3. 选中台词后拖动右边缘修剪，或填写精确时长并点击“应用时长”。后续台词及相关轨道会同步移动。精确时长会锁定，语音适配不会再次拉长它。
4. “帧吸附”使修剪对齐视频帧。按住 Shift 临时关闭吸附，Esc 取消正在进行的拖动。
5. 使用“撤销 / 重做”或在时间轴区域按 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤回或重做修剪。其他面板修改项目后，旧的修剪记录会失效，避免覆盖后续编辑。
6. “编辑”提供台词、角色、飞船及场景事件的详细控制；“镜头”设置构图和遮挡；“输出”设置视频、背景音乐及角色语音。
7. 在“项目”保存 JSON，或在“输出”渲染 MP4。渲染时隐藏工作区并恢复完整画幅。

撤销记录只在当前会话保留，最多保留 32 次修剪，并限制大型轨道数据的历史占用。镜头、移动和场景事件轨道目前支持选择和定位；对应内容在详细编辑工具中修改。

## 开发验证

```powershell
cargo test --offline --lib replay::
cargo build --offline
```

原生 UI 验证应在独立工作目录使用合成数据。调试构建设置 `WILLOWBLOSSOM_OFFLINE=1` 可保留本地聊天资源并禁用 NapCat 连接；此开关不影响发布构建。需要无声预览时，将合成台词的 `speech_enabled` 设为 `false`。

回归检查包括：导入与保存项目、选中台词、边缘修剪、精确时长、撤销/重做、吸附、面板缩放、合成字幕与画幅一致，以及退出工作区后恢复主界面。额外检查聊天界面异步发送结果继续落盘，纯聊天模式启动不会被工作区遮挡。
