## 自动备份

在“TRPG设置 → 自动备份”中可启用/停用自动备份、调整间隔（默认 10 分钟）和保留份数（默认 30 份），也可以随时点击“立即备份”。备份会先把聊天记录、DeepSeek 总结、体素场景、战斗轮等主要存储落盘，再把 `.data/willowblossom` 下的全部顶层数据文件（聊天信息、玩家角色、体素场景、战斗轮、回放移动历史、UI 状态等）和角色立绘目录复制到 `.data/willowblossom/backups/<UTC时间戳>/`，每份备份附带 `manifest.json` 清单。tts（约 19GB）、图片缓存、日志、回放成品、场景截图和视频渲染缓存等大目录不会进入备份；超出保留份数的旧备份会自动删除。

同一面板还提供“恢复备份”：下拉选择备份后需二次确认。恢复会先把备份文件复制回数据目录（不会覆盖当前的备份设置本身），再立即重载聊天、DeepSeek 总结、体素场景和战斗轮，因此这些内容恢复后立即可用；界面记忆、键位等其余设置需要重启应用后完全生效，建议恢复后尽快重启。若想恢复的数据仍在备份中但不在列表里，可手动把 `backups/<时间戳>/` 下的文件复制回 `.data/willowblossom/`。

## GM 赛后统计

在“战斗轮”窗口点击“打开GM赛后统计”，或点击某个战斗轮的“统计”按钮即可查看；GM 把“进行中”切换为休整时也会自动打开本场结果。统计窗口只读取 GM 本地保存的战斗事件，不会发送到 QQ、玩家窗口、DeepSeek 或 MCP。

角色总览同时列出输出/承受伤害、输出/受到治疗与过量治疗护盾、K/A/D、获得经验、施加状态次数和有效结算事件数。横向条形图可切换有效伤害、承受伤害、伤害基础值、有效治疗/护盾、受到治疗/护盾、治疗基础值、经验、击杀、助攻、死亡、状态和结算事件，并按参战者、技能/来源、参战者+技能、目标或回合聚合。

筛选支持本场/全部历史、玩家角色/单位、来源角色、技能名称、目标、起止回合、Top-N、零值角色和数值/名称排序。图表与角色总览都可复制为 TSV，便于直接粘贴进表格软件。实际扣血后的伤害才计入有效伤害；即时、延迟和持续状态伤害/治疗使用同一事件口径。范围技能按每个目标各记一条生效事件，因此事件数表示命中/生效次数而不是施法次数。旧备份仍可统计已有伤害、治疗和状态记录；结构化经验与 K/A/D 从本功能启用后的新结算开始积累。

## TRPG 回放

点击主界面右上角的“🎬 回放”打开回放工作室。DM 可以选择公开、指定队伍、指定玩家或“全部 / All”范围，开始实时录制，也可以从当前战役的既有聊天生成回放；“全部”包含 GM 能读取的私聊、隐藏队伍、GM 和系统内容，不能直接公开发布。新消息会保存说话者当时的玩家回合和整数体素坐标；旧消息缺少快照时会使用当前立牌位置（没有立牌则使用原点）和当前回合生成，并在编辑器中明确标为估算，DM 可再校正。回放编辑器允许全选/取消台词、修改文本、回合、XYZ 和区域，还可拖放台词卡片重新排序、删除草稿台词或新增空白 DM 台词，并按 XZ 水平距离自动分区；默认每个区域块最多播放三个不同回合，DM 可以重新排序、拆分、合并或把台词移动到其他块，因此区域顺序可以覆盖全局消息时间顺序。台词会按中英文字符和标点估算阅读时长，单句最长 9.75 秒，并以约 0.27 秒的短间隔连续播放。默认使用 15 FPS 快速导出（约为 30 FPS 一半的截图数量），也可选择 12、24、30 或 60 FPS；点击“渲染并导出 MP4”后，应用会隐藏编辑器界面、逐帧渲染场景与台词层，并通过 PATH 中的 FFmpeg 输出 H.264 MP4。DM 的角色立绘和姓名显示在左侧，玩家显示在右侧；每个 QQ 发送者使用稳定且不同的专业配色，角色图片会优先复用 QQ 消息图片缓存，保持原始比例并显示在姓名牌上方。

配置 `.env` 中的 `DEEPSEEK_API_KEY` 后，回放工作室可直接使用 DeepSeek 润色台词并选择受限镜头，无需额外启用。“自定义导演要求”输入框可指定角色口癖、节奏和镜头风格，最多发送 2000 字。导演使用开启思考模式的 `deepseek-v4-pro`，返回逐句润色台词以及受限的构图和运动指令；本地会验证每个原始台词索引恰好出现一次，再重新计算台词时长并生成平滑镜头轨迹。DeepSeek 不控制坐标或旋转，只能建议固定镜头或沿光轴平滑推拉；三人及以上时本地优先使用队伍正面中央机位，避免侧拍导致角色互相遮挡。DeepSeek 只接收所选发布范围已经允许显示的台词和角色模型是否存在，不得新增剧情事实或扩大可见范围。“录制 DM 自由镜头”默认关闭，只有手动开启后才持续采集 DM 镜头。

“DeepSeek 导演并导出”提供一键输出：重建可见聊天、等待 DeepSeek 返回润色台词和逐句构图/运动方案、本地验证后将镜头强制对准正在发言且拥有场景立牌的角色；找不到对应角色时才按方案生成极慢的短距离环境移动，然后逐帧渲染并编码 MP4。环绕运动已禁用，镜头转换会覆盖约 70% 的当前台词并限制每句的物理移动距离，避免跨越飞船的快速运镜。DeepSeek 通过受限镜头指令控制成片节奏，不直接执行任意坐标或访问隐藏内容。

DeepSeek 完成后可在“查看 DeepSeek API 原始响应”中查看并复制 API 返回的 `message.content`；API 密钥和模型思考过程不会显示。导演方案及其输入指纹会持久保存；应用重启后，如果战役、发布范围、台词、说话者立牌、自定义导演要求均未改变，会直接应用已保存方案而不再次请求 API。“DeepSeek 导演并导出”会等待有效导演方案真正返回并应用后再开始渲染，不再先生成本地环绕镜头。BGM 完全由 GM 本地管理：将 MP3、WAV、OGG、FLAC、M4A 或 AAC 文件放入空的 `assets/audio` 文件夹，在导出区点击“重新扫描”并选择曲目即可。应用不再附带或通过 AI 生成音乐；FFmpeg 会按视频长度循环所选文件、淡入淡出并编码为 AAC。

视频配音使用本地 EmotiVoice 中文模型，不上传聊天内容。首次使用前运行 `powershell -ExecutionPolicy Bypass -File scripts/setup_emotivoice.ps1`。应用通过单个常驻 GPU 进程加载模型，每个 QQ 号会稳定分配一个固定说话人 ID，也可在带滚动条的角色语音设置中手动选择或随机更换。EmotiVoice 的声音较机械，但生成快且同一玩家不会因台词内容改变声线。DM/玩家声像在导出视频中分别偏左/偏右。DeepSeek 导演同时返回正常显示的 `text` 和只供语音使用的 `speech_text`，把 AI、英文缩写和阿拉伯数字改成中文谐音或读法；本地规则会在缺失时兜底，导出画面仍显示原始正常文字。播放与 MP4 导出从同一时间线起点使用完全相同的镜头、字幕、语音文本和角色设置。整体语速默认 1.10 倍，可无上限统一调整；整体台词停留默认 1.00 倍，也可无上限统一缩放字幕停留、台词间隔和导演镜头时间。两项设置均随回放项目 JSON 保存。

回放发布范围默认选择“全部 / All”；公开回放只包含公开消息，队伍和玩家回放在写入事件前执行访问检查。播放时角色立牌会采用每句保存的回合位置，停止播放或完成视频渲染后会恢复 DM 播放前的体素场景和立牌位置。可选的 `*.willow-replay.json` 只用于保存和再次编辑回放项目，不是最终交付格式；旧版项目会作为“旧时间线”兼容载入，不会伪造历史坐标。
